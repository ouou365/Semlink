# 🧠 Semlink — 智慧代理知識工作區（Agentic Knowledge Workspace）

**讓你的 Obsidian 知識庫思考、協作、行動。**

**繁體中文** | [English](README.md) | [简体中文](README_CN.md) | [日本語](README_ja.md) | [한국어](README_ko.md) | [Deutsch](README_de.md) | [Français](README_fr.md) | [Español](README_es.md) | [Português](README_pt.md) | [Italiano](README_it.md) | [Русский](README_ru.md)

Semlink 把你的 Obsidian 知識庫變成一個智慧代理知識工作區——一位住在你側邊欄的 AI 助手：搜尋你寫過的每一個字，用真正的工具推理，每條結論都引用回你的筆記，還能一鍵分享它的所得。完整的智慧代理就內建在外掛裡：不需要 Claude Desktop、不需要 Cursor、不需要終端機、不需要安裝任何第三方用戶端。帶上你自己的 API Key，你的知識庫就開始思考。

## 🤔 為什麼是 Semlink？

你寫了很多年。然後想問一個關於自己知識的問題——流程卻變成：回憶在哪個資料夾、Ctrl+F、複製貼上進聊天視窗、遺失上下文。

多數 Obsidian AI 外掛依賴第三方智慧代理用戶端——而那些用戶端是為程式設計打造的智慧代理應用程式。你得到的是一個順路看看筆記的程式設計助手，而不是真正工作在知識庫裡的智慧代理。

Semlink 反其道而行：

**工作區就是知識庫，智慧代理是內建的——不是後來才掛上去的。** 裝上外掛、貼上 key、開始提問。智慧代理思考、呼叫工具、讀你的筆記、給出帶編號引用的回答——全程都在 Obsidian 裡。你不必相信這個回答，你看著它產生，然後檢驗它。

| 智慧代理循環（檢索→讀→推理） | ✅ 9 個工具，模型自主決定讀什麼 | 🟡 經外部用戶端執行 |

| 分享回答 | ✅ LAN 網頁 + QR 碼，隨時撤銷 | ❌ 複製貼上 |

### 有意為之的設計

🧠 **智慧代理是住戶，不是訪客。** 智慧代理需要的一切——搜尋、工具、思考軌跡、引用、分享——都在外掛裡。外部 AI 用戶端可以透過 MCP 進來，但那是可選的加分項，絕非前提。

🗄️ **本機優先，是結構使然。** 索引就是你磁碟上的一個 SQLite 檔案。Semlink 沒有伺服器——不是「我們承諾不上傳你的筆記」，而是根本沒有可以上傳的地方。

🔑 **BYOK，而且不必瞎猜。** 24 家對話供應商目錄（1,800+ 個模型，附價格與上下文視窗）加上專屬的嵌入供應商目錄，幾下點擊完成設定；Ollama 這類本機執行環境連 key 都不用。Semlink 不加價、不經手 token——你的供應商直接向你計費。

🪟 **知識庫的原生住民。** 把筆記拖進對話即可附加，回答一鍵存回筆記，上下文用量環即時可見。你打字時索引主動讓路。工作區就在你筆記已經在的地方——無需匯出，無需同步。

## ✨ 特色功能

### 🔗 真正跟得上的引用

每一輪問答執行一個統一的編號註冊表，貫穿思考軌跡、答案本文和來源卡片——答案裡的 `[3]` 就是你剛才看著模型讀過的那個 `[3]`。點擊引用，Obsidian 直接開啟它的來源筆記、定位到出處。一個回答的好壞，取決於你能否拿筆記核對它——那就核對。

### 📡 不匯出任何東西，直接分享回答

發現了值得展示的東西？一鍵把整場問答——問題、思考軌跡、回答、來源卡片——發布成 LAN 裡的一個乾淨網頁。傳送連結或 QR 碼，對方在任何瀏覽器開啟：不需要 Obsidian、不需要帳號、不需要安裝。停止分享，頁面隨即下線。任何東西都不會離開你的網路。

### 🪟 即時看著智慧代理工作

回答不是唯一的產出——推理過程也是。思考即時串流，每一次工具呼叫（`search_notes` → `get_section` → …）連同結果全部留痕，上下文用量環顯示模型視窗的佔用，旁邊還有快取命中率。模型看過什麼，你就看到什麼——這正是全部意義所在。

## 🚀 快速上手

1. **安裝** — 到[外掛頁面](https://community.obsidian.md/plugins/semlink)一鍵安裝，或在 設定 → 第三方外掛 中搜尋 "Semlink"。
2. **設定** — 從目錄挑選供應商（或貼上自訂端點）並填入 API key。三步驟引導會驗證對話 + 嵌入設定並開始索引。
3. **提問。** 開啟側邊欄：「關於卡片盒筆記法我都寫過什麼？」——然後看：思考 → `search_notes` → `get_note` → 帶 [1][2][3] 的回答。

就這樣。不需要智慧代理用戶端，不需要伺服器設定。你的筆記永遠不會被修改——Semlink 只會讀取。

## 🧠 思考——展示工作過程的智慧代理

- **九個內建工具**，回答時由模型自主決定取用什麼：語意搜尋、讀筆記、讀章節、相似筆記、regex grep、帶時間戳記的索引列表、目前筆記感知。它不會檢索三個片段就憑空硬掰：它先搜尋、讀對章節，並展示每一步。
- **可檢驗的思考。** 每個回答都附帶模型的推理與每一次工具呼叫（`search_notes` → `get_section` → …），即時串流——不是自信的黑盒子。
- **經得起核對的引用。** 每輪一個統一編號註冊表，貫穿思考軌跡、答案本文和來源卡片；點擊引用直達它來自的那則筆記（和那一行）。
- **觸及全部筆記的搜尋**：一句自然語言按含義查詢你寫過的每一則筆記；當你確實知道確切字串時，還有相似筆記推薦和 regex grep。

## 🤝 協作——知識按你的條件走出孤島

- **透過 LAN 分享對話**：一鍵把問答發布成一個乾淨的網頁——傳送連結或 QR 碼，對方在任何瀏覽器開啟，你隨時可撤銷分享。任何東西都不會離開你的網路。
- **回答變成筆記**：任何回答一鍵存回知識庫。
- **拖曳即附加**：把筆記拖到面板任意位置——`[[雙鏈]]` 行內解析——智慧代理會優先讀它。
- **可選：放你的其他 AI 進來。** 同樣的工具也以本機 MCP 伺服器提供，Claude Desktop、Claude Code 和 Cursor 也能搜尋並引用你的庫。純屬可選——內建智慧代理不需要幫手。

## ⚡ 行動——即時掌控

- **RAG 儀表板，不是進度條**：知識庫指標、真實的逐筆記嵌入進度，索引／自動嵌入開關即時生效——執行中途也能切換。
- **換設定不用儀式感**：更換嵌入模型會自動觸發全量重建索引；引導會重新驗證 key 並把你帶到正確的步驟。
- **即時索引**隨寫隨嵌入，擷取每一次檔案變更——你工作時索引主動讓路，編輯器絕不卡頓。
- **命令面板**統管索引、MCP、偵錯日誌與進度。

## 🔑 BYOK — 自帶你的 key

任何 OpenAI 相容或 Anthropic 相容端點都可用——DeepSeek、GLM、SiliconFlow、OpenAI、Anthropic、OpenRouter、Ollama、LM Studio，以及內建目錄裡的 1,800+ 更多模型。關鍵是：

- **對話模型**：從附價格與上下文視窗的目錄中挑選，或新增自訂端點（包括免 key 的本機執行環境）
- **嵌入模型**：專屬的嵌入供應商目錄——SiliconFlow BGE-M3 預先配置；Jina、Voyage、Nomic、Mixedbread 等，或免 key 的本機嵌入端點
- **你的 key、你的費率、無限次切換**——模型用量由你的供應商計費；Semlink 從不經手一分錢

## 🌐 MCP — 可選，為你的其他 AI 準備

內建智慧代理自身就是完整的。如果你也在用 Claude Desktop、Claude Code 或 Cursor，同樣的工具會以本機 MCP 伺服器提供：

```json
{ "mcpServers": { "semlink": { "type": "http", "url": "http://127.0.0.1:3001/mcp" } } }
```

僅監聽本機，可選存取金鑰。無雲端中轉。

## ❓ 常見問題

**需要 Claude Desktop、Cursor 或其他 AI 用戶端嗎？**
不需要。完整的智慧代理——思考軌跡、工具呼叫、引用、分享——全在外掛內執行。MCP 的存在是為了讓外部 AI **也能**讀你的庫，絕不是因為它們非得參與。

**我的資料會被傳送到哪裡？**
索引位於你磁碟上的外掛資料夾 `data/` 內。僅有的網路請求都發向你自行設定的供應商；LAN 分享也只發生在你自己的網路裡。詳見[隱私權政策](https://getsemlink.com/privacy.html)。

**和 Copilot for Obsidian 有什麼不同？**
Copilot 的 Agent 走外部的 opencode、RAG 走外部的 Miyo——都是要額外安裝、與外掛並行的外部工具。Semlink 把整個循環留在 Obsidian 裡：你看得到思考與每一次工具呼叫，模型自己決定讀哪些筆記，回答引用可開啟的具體筆記。如果 Copilot 對你夠用，留著它——Semlink 是給想要一個工作區、而不是更多用戶端的人準備的。

**需要 API key 嗎？**
Semlink 設計上就是 BYOK——但「自己的 key」也包括 Ollama 這類免 key 的本機執行環境，對話和嵌入都適用。雲端免費額度（SiliconFlow、Groq…）也完全夠用。

**索引存在哪裡？**
外掛資料夾內的 `data/vault.db`（SQLite）和 `data/vectors.bin`。隨時可刪除並重建；任何東西都不會離開你的電腦。

**該用哪個模型？**
任何你喜歡的長上下文對話模型——回答會大段引用筆記。嵌入很便宜也不頻繁（BGE-M3）。
