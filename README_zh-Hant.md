## 🤔 為什麼是 Semlink？

你寫了很多年。然後想問一個關於自己知識的問題——流程卻變成：回憶在哪個資料夾、Ctrl+F、複製貼上進聊天視窗、遺失上下文。

其他 Obsidian AI 外掛也能「和筆記聊天」，但不會讓你看到工作過程：多數 RAG 外掛在黑盒子裡檢索幾個片段就直接回答——片段不對，語氣卻很自信。Smart Connections 能找相關筆記但從不回答問題。Omnisearch 停在關鍵字。而「硬核」路線——把筆記貼進 ChatGPT、或在終端機裡跑 Claude Code——意味著你的知識住在編輯器之外。

Semlink 反其道而行：

**智慧代理住進你的庫裡——而且你看著它做事。** 每個回答都附帶模型的思考過程、它呼叫的每一個工具（`search_notes` → `get_note` → …），以及指回你筆記的編號引用。你不必相信這個回答，你可以檢驗它。

### 三個有意為之的設計

🗄️ **本機優先，是結構使然。** 索引就是你磁碟上的一個 SQLite 檔案。Semlink 沒有伺服器——不是「我們承諾不上傳」，而是根本沒有可以上傳的地方。

🔌 **用你已經在付費的模型。** DeepSeek、GLM、SiliconFlow、OpenAI、Claude、Ollama、LM Studio——任何 OpenAI 或 Anthropic 相容端點。Semlink 不加價、不經手 token；用量由你的供應商直接計費。

🪟 **知識庫的原生住民。** 把筆記拖進對話即可附加，回答一鍵存回筆記，上下文用量環即時可見。你打字時索引主動讓路。智慧代理在你筆記已經在的地方工作——無需匯出，無需同步。

## 🎯 適合我嗎？

**✅ 適合，如果你：**

- 累積了幾個月甚至幾年的筆記，想用自然語言「問」它們
- 想要可檢驗的推理——思考、工具呼叫、引用——而不是自信的黑盒子
- 在意筆記從不離開你的電腦
- 已有 LLM API key（或跑本機模型），反感中間商加價
- 用 Claude Desktop、Claude Code 或 Cursor——並希望它們也能讀你的庫

**❌ 不適合，如果你：**

- 想要 ChatGPT 的通用替代——Semlink 只回答來自你庫的問題，不連網
- 期望零設定——你需要一個嵌入 API key 和一個對話模型 key（免費額度可用）
- 需要團隊協作或雲端同步——設計上就沒有後端

## 🚀 快速上手

1. **安裝** — 在 Obsidian 的 設定 → 第三方外掛 中搜尋 "Semlink" 一鍵安裝，或直接開啟[外掛頁面](https://community.obsidian.md/plugins/semlink)安裝。
2. **設定** — 貼上嵌入 API key（預置 SiliconFlow BGE-M3）和對話供應商 key。三步驟引導會驗證兩者並開始索引。
3. **提問。** 開啟側邊欄：「關於卡片盒筆記法我都寫過什麼？」——然後看：思考 → `search_notes` → `get_note` → 帶 [1][2][3] 的回答。

就這樣。你的筆記永遠不會被修改——Semlink 只會讀取。

## ✨ 功能

### 🕵️ 會用工具的智慧代理，不只是聊天機器人

九個內建工具——語意搜尋、讀筆記、讀章節、相似筆記、regex grep、索引列表（帶時間戳記）、目前筆記感知——回答時由模型自主決定取用什麼。它不會只檢索三個片段就憑空硬掰：它先搜尋、讀對章節，並展示每一步。

### 🔍 觸及全部筆記的語意搜尋

按含義而非關鍵字查詢——一句自然語言觸及你寫過的每一篇筆記。當你確實知道確切字串時，還有相似筆記推薦和 regex grep。

### 🪟 知識庫的原生住民

- **拖曳附加**：把筆記拖到面板任意位置——`[[雙鏈]]` 行內解析
- **回答存為筆記**：一鍵儲存回知識庫
- **看得見的上下文**：即時上下文環顯示模型視窗佔用，旁邊是快取命中率——回答變淺時，你先知道原因，而不是怪模型
- **首頁問題卡片**：精選範例問題，部分來自你最近的筆記

### ⚡ 即時索引

檔案變更自動擷取並隨寫隨嵌入——你工作時索引主動讓路，編輯器絕不卡頓。

## ❓ 常見問題

**我的資料會被傳送到哪裡？**
索引在你的外掛資料夾 `data/` 下，位於你的磁碟。僅有的網路請求都發向你設定的供應商。詳見[隱私權政策](https://getsemlink.com/privacy.html)。

**和 Copilot for Obsidian 有什麼區別？**
透明度與智慧代理循環：你看到思考和每一次工具呼叫，模型自己決定讀哪些筆記，回答引用可以打開的具體筆記。如果 Copilot 夠用，留著它——Semlink 是給想看著它做事的人準備的。

**需要 API key 嗎？**
需要——Semlink 設計上就是自帶 key。免費額度（SiliconFlow、Groq…）對嵌入和對話都夠用。

**索引存在哪裡？**
外掛資料夾內的 `data/vault.db`（SQLite）和 `data/vectors.bin`。隨時可刪可重建；任何東西都不會離開你的電腦。

**該用哪個模型？**
任意你喜歡的長上下文對話模型——回答會大段引用筆記。嵌入很便宜也不頻繁（BGE-M3）。
