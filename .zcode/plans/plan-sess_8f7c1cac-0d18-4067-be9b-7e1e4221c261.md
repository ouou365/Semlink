# 新增右侧边栏语义搜索视图

## 目标
在 Obsidian 右侧边栏添加一个语义搜索面板，用户输入自然语言查询，复用现有 `EmbeddingClient.embed()` + `VectorStore.search()`（均走 worker 线程，不阻塞 UI），返回最相关的笔记片段列表，点击可跳转打开笔记。

## 一、新建 `src/search-view.ts` — 语义搜索视图

实现 `class SemanticSearchView extends ItemView`，遵循现有 progress-modal 的 DOM 风格（createEl/createDiv + 保留引用增量更新）。

- `getViewType()` → `"semlink-semantic-search"`
- `getDisplayText()` → `t("searchViewTitle")`
- `getIcon()` → `"search"`
- `constructor(leaf, store, client, vault)` — 注入 VectorStore 和 EmbeddingClient（与 McpServer 一致的依赖注入模式）
- `onOpen()` — 构建 DOM：搜索输入框（Enter 触发）+ 搜索按钮 + 状态区 + 结果列表容器
- `runSearch()` — 调用链：`client.embed([query])` → `store.search(embeddings[0], limit, threshold)` → `renderResults()`
  - 搜索时显示 loading 态，输入防抖（window.setTimeout）
  - catch 错误显示 `searchError` + 错误消息
- `renderResults(results)` — 每个结果渲染为卡片：标题(heading/basename)、路径(text-muted)、预览(contentPreview)、相似度徽章(score%)、点击打开笔记
- `openNote(notePath)` — `vault.getAbstractFileByPath` → `workspace.getLeaf(false).openFile(file)`

## 二、修改 `main.ts` — 注册视图 + ribbon + 命令

在第 106 行 `addSettingTab` 之后新增：
- `import { SemanticSearchView }`
- 定义常量 `SEARCH_VIEW_TYPE = "semlink-semantic-search"`
- `this.registerView(SEARCH_VIEW_TYPE, (leaf) => new SemanticSearchView(leaf, this.store, this.client, this.app.vault))`
- `this.addRibbonIcon("search", "Semlink 语义搜索", () => this.activateSearchView())`
- `this.addCommand({ id: "semlink-open-search", name: t("cmdOpenSearch"), callback: () => this.activateSearchView() })`
- 新增方法 `activateSearchView()`：
  - 查找已有视图 leaf（`getLeavesOfType`），没有则 `getRightLeaf(false)` + `setViewState`
  - `workspace.revealLeaf(leaf)` 确保右侧边栏展开并聚焦

## 三、修改 `src/i18n.ts` — 新增翻译 key

在 `S` 对象末尾（reportBug 之后）追加 `// ──── Semantic Search View ────` 区块：
- `searchViewTitle` / `searchPlaceholder` / `searchButton` / `searchSearching`
- `searchNoQuery` / `searchNoResults` / `searchError`
- `searchResultOpen` / `searchLimit` / `searchScoreLabel`
- `cmdOpenSearch` / `searchNeedApiKey`（未配置 API Key 时的提示）

注：`t()` 不做模板替换，占位符用 `.replace()` 或拼接处理（与现有 apiKeyDesc 的 `{site}` 一致）。

## 四、修改 `styles.css` — 搜索视图样式

追加 `.semlink-search-view` 及子元素样式（用 `semlink-` 前缀，与 manifest id 一致）：
- `.semlink-search-bar`（输入框+按钮 flex 布局）
- `.semlink-search-input`（全宽输入框）
- `.semlink-search-status`（loading/错误/空结果提示，text-muted）
- `.semlink-search-results`（结果列表滚动区）
- `.semlink-search-result`（结果卡片，可点击 hover 效果）
- `.semlink-search-result-title` / `-path` / `-preview` / `-score`
- 全部用 Obsidian CSS 变量（--background-modifier-hover、--text-muted、--color-accent 等）

## 五、搜索调用链（复用现有代码，零新逻辑）

```
用户输入 → runSearch()
  → await this.client.embed([query])           // embedding-client.ts:80，走网络
  → await this.store.search(embeddings[0], 10, 0.3)  // vector-store.ts:230，走 worker
  → renderResults(results: SearchResult[])
  → 点击 → openNote(notePath)
```
与 mcp-server.ts:384 `toolSearchNotes` 完全一致的调用范式。
