## 🤔 なぜ Semlink なのか？

何年も書きためてきたのに、いざ自分の知識について質問しようとすると、ワークフローはこうなります。どのフォルダだったか思い出して、Ctrl+F で検索し、チャットウィンドウにコピペして、そして迷子になる。

他の Obsidian AI プラグインもノートとチャットはできます。しかし見せてくれないのは「仕事の過程」です。ほとんどの RAG プラグインは、ブラックボックスの裏で少数のチャンクを取得したまま、外れたチャンクでも自信満々に答えてしまいます。Smart Connections は関連ノートを見つけるだけで、答えてはくれません。Omnisearch はキーワードで止まります。そして「本気」の道 — ノートを ChatGPT に貼ったり、ターミナルから Claude Code を操ったり — は、知識がエディタ以外の場所に置かれることを意味します。

Semlink は逆の発想で作られています:

**エージェントは Vault の中に住み、その仕事ぶりを目撃できます。** すべての回答には、モデルの思考プロセス、実行されたすべてのツール呼び出し（`search_notes` → `get_note` → …）、そして自分のノートを指し戻す番号付き引用が付きます。回答を鵜呑みにする必要はありません。自分で確認できるのです。

### 意図して貫いた 3 つの選択

🗄️ **構造そのものがローカルファースト。** インデックスは自分のディスク上の SQLite ファイルです。Semlink のサーバーは存在しません — 「ノートをアップロードしないと約束します」ではなく、アップロードする先が物理的に存在しないのです。

🔌 **すでに払っているモデルをそのまま使える。** DeepSeek、GLM、SiliconFlow、OpenAI、Claude、Ollama、LM Studio — OpenAI または Anthropic 互換の任意のエンドポイント。Semlink は上乗せ料金を取らず、あなたのトークンに触れません。利用料はプロバイダーから直接あなたに請求されます。

🪟 **Vault の住人。** ノートをチャットにドラッグして添付、回答をワンクリックでノートとして保存、コンテキストリングがリアルタイムに満ちていくのを見守る。入力中はインデックス処理が道を譲ります。エージェントはノートが住む場所で働きます — エクスポートも同期も不要です。

## 🎯 自分に合う？

**✅ 次に当てはまる人に:**

- 数か月（あるいは数年）分のノートがあり、それにふだんの言葉で*質問*したい
- 検証できる推論 — 思考、ツール呼び出し、引用 — が欲しい。自信満々なブラックボックスはいらない
- ノートがマシンの外に出ないことを重視する
- すでに LLM の APIキーを持っている（またはローカルモデルを動かしている）仲介者の上乗せにうんざりしている
- Claude Desktop、Claude Code、Cursor を使っていて、そこからも Vault を読ませたい

**❌ 次に当てはまる人には合いません:**

- 汎用の ChatGPT 代わりを求めている — Semlink はインターネットではなく Vault から答えます
- 設定ゼロを期待している — 埋め込み用 APIキーとチャットモデルのキーが必要です（無料枠でも可）
- チーム共用やクラウド同期が必要 — 設計上、バックエンドは存在しません

## 🚀 クイックスタート

1. **インストール** — Obsidian の 設定 → コミュニティプラグイン で「Semlink」を検索してワンクリックで導入、または[プラグインページ](https://community.obsidian.md/plugins/semlink)から直接インストール。
2. **設定** — 埋め込み用の APIキー（SiliconFlow BGE-M3 を事前設定済み）とチャットプロバイダーのキーを貼り付けます。3 ステップのオンボーディングが両方を検証し、インデックス作成を開始します。
3. **質問する。** サイドバーを開いて *「Zettelkasten について何を書いたっけ？」* — 見てください: 思考 → `search_notes` → `get_note` → [1][2][3] 付きの回答。

これだけです。ノートが変更されることは一切ありません — Semlink は読むだけです。

## ✨ 機能

### 🕵️ チャットボットではなく、ツールを使うエージェント

9 種類のツールを内蔵 — セマンティック検索、ノート読取、セクション読取、類似ノート、regex grep、インデックス一覧（タイムスタンプ付き）、現在のノートの把握 — モデルが回答しながら必要なものを判断します。3 つのチャンクを取ってきてその上で幻覚を見るのではなく、検索し、適切なセクションを読み、すべてのステップを見せます。

### 🔍 すべてに届くセマンティック検索

キーワードではなく意味で検索 — 自然言語のクエリ 1 つで、これまで書いたすべてのノートに届きます。正確な文字列がわかっているときのために、類似ノートの候補や regex grep も用意されています。

### 🪟 Vault の住人

- **ドラッグ & ドロップ**: パネルのどこにでもノートをドロップして添付 — `[[wiki リンク]]` はインラインで解決されます
- **回答をノートとして保存**: ワンクリックで Vault に戻せます
- **見えるコンテキスト**: ライブのコンテキストリングでモデルのウィンドウの充填率がわかり、横にキャッシュヒット率も表示 — モデルを責める前に、回答が浅くなった理由がわかります
- **ホームの質問カード**: 厳選されたプロンプト例。一部はあなたの最近のノートから選ばれます

### ⚡ リアルタイムインデックス

ファイルの変更は自動で検出され、書くそばから再埋め込みされます。作業中はインデックス処理が道を譲るので、エディタがもたつくことはありません。

## 🤖 モデルは持ち込み（BYOK）

OpenAI 互換または Anthropic 互換の任意のエンドポイントが使えます: DeepSeek（事前設定済み）、SiliconFlow、GLM、OpenAI、Anthropic、Ollama、LM Studio、OpenRouter — キーも料率もあなたのもの、切り替えは無制限。大事なポイント:

- **チャットモデル**: 長いコンテキストが有利 — 回答はノートをたっぷり引用します
- **埋め込みモデル**: SiliconFlow 経由で BGE-M3（1024 次元）を事前設定済み。互換性のある埋め込みエンドポイントなら何でも動きます
- モデルの利用料はプロバイダーに請求されます — Semlink がそのお金に触れることは一切ありません

## 🌐 MCP — 他の AI にも記憶を

同じツール群はローカル MCP サーバーとしても動くので、Claude Desktop、Claude Code、Cursor からもあなたの Vault を検索・引用できます:

```json
{ "mcpServers": { "semlink": { "type": "http", "url": "http://127.0.0.1:3001/mcp" } } }
```

localhost のみ、アクセスキーは任意。クラウド中継はありません。

## ❓ FAQ

**データはどこかへ送られますか？**
インデックスはプラグインフォルダ内の `data/` に、あなたのディスク上で置かれます。ネットワーク通信は*あなたが*設定したプロバイダーへの呼び出しだけです。詳しくは[プライバシーポリシー](https://getsemlink.com/privacy.html)をご覧ください。

**Copilot for Obsidian とは何が違いますか？**
透明性とエージェントループです: 思考とすべてのツール呼び出しが見え、モデルが読むべきノートを選び、回答は開ける具体のノートを引用します。Copilot で満足なら、そのままで構いません — Semlink は「仕事の過程」を見たいときのためのものです。

**APIキーは必要ですか？**
はい — Semlink は BYOK（キー持ち込み）方式で設計されています。埋め込みにもチャットにも、無料枠（SiliconFlow、Groq など）で十分動きます。

**インデックスはどこに置かれますか？**
プラグインフォルダ内の `data/vault.db`（SQLite）と `data/vectors.bin` です。いつでも削除して再インデックスできます。データがマシンの外に出ることは一切ありません。

**どのモデルを使えばいいですか？**
好きな長いコンテキストのチャットモデルでどうぞ — 回答はノートをたっぷり引用します。埋め込みは安価で頻度も低く抑えられます（BGE-M3）。
